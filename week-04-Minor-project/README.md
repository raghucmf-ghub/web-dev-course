Week 4 minor project - Todo and Notes app

Hi, this is my minor project 4 submission. I made two small apps in react inside one project: one is a todo list and the other is a notes app. There are buttons at the top to switch between them.

Things I made in this project:

Todo App:

- You can add daily tasks with a due date.

- You can check the box to mark if it is done or pending.

- If you make a mistake you can click edit and change the text.

- Delete button to remove tasks.

- Filter buttons to see all tasks, only pending tasks, or only completed tasks.

- It also saves to localstorage so if you refresh the page the items are still there.

Notes App:

- You can create notes with a title, description, and choose a category (study, work, personal, general).

- You can search through your notes by typing in the search box.

- Filter notes by category.

- Edit and delete options for each note.

- Shows the date and time when the note was created.

- Saves to localstorage too.

React and JS concepts used:

- Used components (TodoApp, TodoItem, NotesApp, NoteItem)

- useState for storing items, input values, and edit state

- useEffect for saving to local storage

- passing data using props

- arrow functions, .map() to display the lists, and .filter() to delete and filter items

How to run it:

1. open the folder in terminal

2. type "npm install" and hit enter

3. type "npm run dev"

4. open the localhost link in your browser to test it
